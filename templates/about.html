About StudentHub

A modern, lightweight student management platform built with Python & Flask.

Empowering Educational Administration

StudentHub is designed to streamline academic operations by providing an intuitive dashboard, fast student directory filtering, profile management, course tracking, and RESTful API endpoints.

Fast & Responsive

Built on lightweight Flask with instant sqlite parameter query execution for zero latency navigation.

Data Integrity

SQLite foreign key constraints and transactional integrity guarantee consistent student records.

Visual Analytics

Live status metrics and course distribution breakdown for administrative decision making.

REST API Support

Built-in JSON endpoint at /api/students for seamless third-party integrations.
